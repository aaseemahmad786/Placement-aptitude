# TCS NQT Compass

A comprehensive 60-Day Aptitude Planner & Preparation Tracker designed specifically for candidates targeting the **TCS National Qualifier Test (NQT)**.

## Features

- **60-Day Structured Curriculum**: Daily modules covering Numerical Ability, Verbal Ability, Reasoning Ability, and Advanced Quantitative / Coding Logic.
- **Interactive Daily Tracker**: Track completion status, progress metrics, and syllabus coverage across all four core domains.
- **Comprehensive Question Bank**: Hundreds of TCS NQT-pattern practice problems with detailed, step-by-step solutions and answer reveals.
- **Formulas & Concept Cheat Sheets**: Rapid revision sheets for essential arithmetic, algebra, geometry, probability, and speed math shortcuts.
- **Mock Assessment & Timer**: Timed assessment modes mimicking TCS NQT section-wise test constraints.
- **Dark / Light Theme & Responsive UI**: Optimized for desktop and mobile study sessions with Tailwind CSS.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Components**: React 19, [Tailwind CSS](https://tailwindcss.com/), [Lucide React](https://lucide.dev/)
- **Database / ORM**: [Drizzle ORM](https://orm.drizzle.team/), PostgreSQL (Neon / Netlify Database) with local embedded PGlite support for zero-config offline development.
- **Deployment**: [Netlify](https://www.netlify.com/)

## Getting Started

### Prerequisites

- Node.js 20+ or 22+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/aaseemahmad786/Placement-aptitude.git
cd Placement-aptitude

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Scripts

- `npm run dev`: Start development server
- `npm run build`: Build production bundle
- `npm run start`: Start production server
- `npm run lint`: Run ESLint checks
- `npm run typecheck`: Run TypeScript compiler type validation
